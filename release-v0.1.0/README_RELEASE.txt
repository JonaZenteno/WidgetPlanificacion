Widget Dashboard v0.1.0

Contenido:
- WidgetDashboard.exe

Uso:
1. Ejecuta WidgetDashboard.exe
2. La aplicacion guardara sus datos en:
   %APPDATA%\WidgetDashboard

Autoinicio silencioso recomendado:
- Instala el ejecutable en una ruta fija.
- Ruta sugerida:
  C:\Apps\WidgetDashboard\WidgetDashboard.exe

Notas:
- Esta build no requiere Python instalado para ejecutarse.
- Si cambias la ruta del ejecutable despues de configurar autoinicio, debes actualizar el lanzador de Startup.
