# Widget Dashboard v0.1.0

Primera release publica del prototipo de escritorio tipo widget para productividad personal en Windows.

## Incluye

- Widget de escritorio minimalista sin bordes
- ToDo con scroll y soporte para tareas multilinea
- Recordatorios con fecha y hora
- Alertas visuales propias con acciones:
  - Posponer 5 min
  - Marcar listo
- Menu contextual para:
  - opacidad
  - color de fondo
  - siempre visible
  - bloquear posicion
  - restaurar estilo por defecto
- Inicio silencioso en Windows sin consola negra
- Build `.exe` para uso diario

## Notas

- Los datos del usuario se guardan fuera del repositorio en `%APPDATA%\\WidgetDashboard`.
- La ruta estable recomendada para la app es `C:\\Apps\\WidgetDashboard\\WidgetDashboard.exe`.
- Si se cambia la ruta del ejecutable estable, hay que actualizar el lanzador de autoinicio.

## Artefactos recomendados

- `WidgetDashboard-v0.1.0-win64.zip`
- `WidgetDashboard.exe`
